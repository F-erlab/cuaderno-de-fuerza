# Cuaderno de Fuerza

Web para seguir un plan de gimnasio full body A/B con **sobrecarga progresiva automática**.

- **Hoy:** sesión del día (alterna A y B) con el peso y las repeticiones objetivo calculados a partir de la última sesión.
- **Progreso:** gráfica e historial por ejercicio.
- **Cuerpo:** registro de peso, ritmo de subida (objetivo 0,25–0,5 kg/mes) y recordatorio de fotos cada 4 semanas.
- **Guía:** proteína diaria según tu peso, comida, descanso y seguridad.

Es un solo archivo `index.html`, sin dependencias. Fuera de Claude los datos se guardan en el navegador (`localStorage`).
